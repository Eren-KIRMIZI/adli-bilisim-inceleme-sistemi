# Modules

1. Case Management — vaka numarası, soruşturma bilgileri, sorumlu, açıklama, tarihler, durum.
2. Evidence Manager — cihaz/envanter, seri no, delil fotoğrafları, teslim kayıtları.
3. Integrity & Chain of Custody — SHA-256/512, erişim geçmişi, denetim kayıtları.
4. Windows Forensics — Registry, Event Logs, kullanıcılar, oturumlar, USB, servisler, Prefetch, LNK, Jump Lists, ShellBags, Recycle Bin.
5. USB Device Forensics — VID/PID, seri no, ilk/son bağlantı, USBSTOR/MountedDevices/MountPoints2/DeviceClasses.
6. Disk Forensics — RAW/E01 içe aktarım, MBR/GPT, NTFS, MFT, silinmiş dosyalar, file carving, hex viewer.
7. Browser Forensics — Chrome/Edge/Firefox: geçmiş, indirmeler, yer imleri, profiller, çerez metadata (parola/token çıkarılmaz).
8. Memory Forensics — işlem listesi, PID/PPID, süreç ağacı, modüller, ağ bağlantıları, açık handle'lar.
9. File Analysis — tür tanıma, imza, hash, metadata, EXIF, hex, karşılaştırma, duplicate.
10. Timeline Analysis — UTC standardizasyon, kaynak koruma, filtreler, kronolojik sıralama.
11. Evidence Relations — kullanıcı-cihaz-dosya-USB ilişkileri, görsel grafik, doğrulanabilir veri.
12. Report Generator — vaka, delil, hash, yöntemler, bulgular, timeline, ekran görüntüleri, sınırlamalar; PDF/HTML.

İleride eklenecek: E-posta, UserAssist/Amcache/SRUM, ağ (PCAP), ADS/slack space, BitLocker durumu, görsel/EXIF.
